# Captures d'Ippitsu

Planches et captures d'écran d'Ippitsu, publiques pour pouvoir les partager par lien (ChatGPT, autres IA, collaborateurs). Le code du jeu est dans un dépôt privé.

Lien direct vers une image : `https://raw.githubusercontent.com/vaucarre/ippitsu-captures/main/<chemin>`

| Dossier | Contenu |
|---|---|
| `monde1/personnages-reference/` | ennemis du monde 1 refaits dans Blender : fiche modèle en haut, rendu en bas, scores de fidélité |
| `monde1/en-jeu/` | captures en jeu du monde 1 (héros et ennemis, rendu Compatibility et Mobile) |
| `monde1/decor-reference/` | planches de référence du décor de l'Archipel (v1 technique : cotes, palette, kit ; v2 : ambiance et lieux) |
| `monde2/personnages-reference/` | ennemis du monde 2 refaits d'après la planche découpée |
| `ui/refonte-v3/` | refonte UI v3 codée dans le jeu (PR de code) : captures en jeu `apres_*` et planche avant / après ; `fusion-1107/` : accueil, options, mondes, victoire après fusion de main (PR #32 à #38) ; `decisions-1107/` : après les décisions de Victor (REJOUER, rouleau de main, coffre aidé, aide dans les Options) |
| `ui/audit-ux/` | revue UI/UX (PR #26) : `captures/` écrans actuels en rendu Mobile, `refonte/` maquettes de la refonte v3, `planches/` synthèse, priorités, avant / après |
| `bouclier/` | effet de bouclier des ennemis (avant / après) |
| `ui/barres-pv/` | barres de PV à l'encre : planches des pistes et des 4 propositions vie + encre en haut, avant / après en jeu (PR ippitsu #27) |
| `monde1/ennemis-fidelite/` | 12 ennemis du monde 1 rapprochés de leurs images IA : `<ennemi>_planche.jpg` (référence, avant, après), `<ennemi>_44.jpg` (caméra du jeu, avant / après), lissage et couture des membres |
| `vfx-pouvoirs/` | revue des FX des 77 pouvoirs (PR ippitsu fx/revue-pouvoirs) : une planche par école (`feu`, `eau`, `foudre`, `vent`, `ombre`, `encre`, `figures` : icône, 4 instants sur main, 4 sur la branche), `cumul.jpg` (9 pouvoirs actifs, avant / après), `lisere_nuit.jpg` (liseré lilas des pièces sombres en monde de nuit) |

Les fichiers gardent le nom de leur passe : le numéro le plus haut est le plus récent.
| `nuit-1106/` | nuit du 06/11 : boucliers du héros et des élites, plâtre du hondō (avant / après) |
| `monde2/` (racine) | refonte du monde 2 : 15 ennemis Meshy, décor, bordure et pont (avant / après) |
| `textes-store/` | pages du site (PR ippitsu docs/textes-store) : politique de confidentialité FR/EN et support FR/EN, rendu HTML |
| `magatama/` | maquette de principe de la boutique Magatama (PR ippitsu design/magatama) |
